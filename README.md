# Myth Hero Reviewer

A single-page study reviewer for three Greek hero stories based on Edith Hamilton's *Mythology*: the Golden Fleece (Jason), Perseus, and Hercules.

- 150 questions
- Identification (type the answer) and matching (5 terms per round, with Shuffle and a check mark on each correct pair)
- Pick one story or review all three
- Light and dark theme

No build step and no dependencies. Open `index.html` in a browser, or host it with GitHub Pages.

## Publish with GitHub Pages

1. Create a new public repository on GitHub.
2. Upload `index.html` and `README.md` to the repository root.
3. Go to Settings, then Pages. Under Build and deployment, set Source to "Deploy from a branch", choose `main` and `/ (root)`, and save.
4. After a minute or so the site is live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.
